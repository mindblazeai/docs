# Contribute a Translation to React

<Callout type="info">
Contribute a translation to the React documentation by navigating to the translation resources and accessing the contribution workflow.
</Callout>

### Step 1 — Open the Translations section

Click the **Translations** link in the **GET INVOLVED** region. This takes you to the translation resources page where you can find information about contributing translations to React.

### Step 2 — Access the contribution workflow

Click the **Contribute** link on the source site page. This opens the interface where you can submit your translation work.

<CaptureImage src="./assets/contribute-a-translation-to-react/step-02.jpg" alt="Step 2" render="eyJoaWdobGlnaHQiOnsieCI6MC40MTI4NjgyOTQ4MDY3ODYxNiwieSI6MC40ODAxNDc5NTc5NDg4MDkzLCJ3aWR0aCI6MC4wNzY1NzA2MjY1NjEzMTUyNiwiaGVpZ2h0IjowLjAyODYwNjY1OTM4NzEwMTY3fX0=" t="3232" />

### Step 3 — Navigate to the scripts directory

Click the **scripts** directory link in the **History** section. This gives you access to the scripts folder where translation-related tooling and processes are located.

<CaptureImage src="./assets/contribute-a-translation-to-react/step-03.jpg" alt="Step 3" render="eyJoaWdobGlnaHQiOnsieCI6MC4wNjQ4MTgwMjY5MDc5MzU3MSwieSI6MC42OTM4MzQ3ODY5MzgzODYzLCJ3aWR0aCI6MC4wMzQzMDQ1OTQwNDMyMjI2MiwiaGVpZ2h0IjowLjAyMjY4ODAzODk4NzA5MDM1fX0=" t="7622" />

## Summary

You have navigated through the translation contribution flow and accessed the scripts directory. From here you can proceed with the translation submission process.
