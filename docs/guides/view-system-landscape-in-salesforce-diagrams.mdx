# View System Landscape in Salesforce Diagrams

<Callout type="info">
Access the System Landscape diagram documentation in Salesforce Diagrams Standard Components.
</Callout>

### Step 1 — Click the Salesforce Diagrams link

Click the **Salesforce Diagrams** link to navigate to the main Diagrams section. This is your entry point to the diagram resources.

### Step 2 — Open Standard Components

Click the **Salesforce Diagrams Standard Components** link. This takes you to the reference documentation for standard diagram components.

<CaptureImage src="./assets/view-system-landscape-in-salesforce-diagrams/step-02.jpg" alt="Step 2" render="eyJoaWdobGlnaHQiOnsieCI6MC4zODM3ODM3ODM3ODM3ODM4LCJ5IjowLjYxNDYwODA3NjAwOTUwMTIsIndpZHRoIjowLjI0Mzc0Mjk2MTcxMTcxMTczLCJoZWlnaHQiOjAuMDUyODUwMzU2Mjk0NTM2ODJ9fQ==" />

### Step 3 — Collapse the message area

Click the **Minimize Agentforce** button in the message area. This collapses the chat interface so you have more space to view the documentation.

<CaptureImage src="./assets/view-system-landscape-in-salesforce-diagrams/step-03.jpg" alt="Step 3" render="eyJoaWdobGlnaHQiOnsieCI6MC45MzMzMzMzMzMzMzMzMzMzLCJ5IjowLjU2NTMyMDY2NTA4MzEzNTQsIndpZHRoIjowLjAyMTYyMTYyMTYyMTYyMTYyMywiaGVpZ2h0IjowLjAyODUwMzU2Mjk0NTM2ODE3Mn19" />

### Step 4 — View the reading time

Click the **5 minute read** indicator to see the estimated time for this section. This helps you understand how long it will take to review the material.

<CaptureImage src="./assets/view-system-landscape-in-salesforce-diagrams/step-04.jpg" alt="Step 4" render="eyJoaWdobGlnaHQiOnsieCI6MC4zMTg5MTg5MTg5MTg5MTg5NCwieSI6MCwid2lkdGgiOjAuNjgxMDgxMDgxMDgxMDgxMSwiaGVpZ2h0IjoxfX0=" />

### Step 5 — Access System Landscape

Click the **System Landscape** link to open the diagram documentation. This displays the System Landscape diagram and its related reference information.

## Summary

You have navigated to the System Landscape diagram in the Salesforce Diagrams Standard Components documentation. You can now review the diagram and its details.
