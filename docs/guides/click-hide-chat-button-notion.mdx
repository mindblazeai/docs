# Click "Hide chat" — Button | Notion

<Callout type="info">
Navigate several key features within the interface, including hiding the chat, searching, and creating and sharing a new page.
</Callout>

### Step 1 — Hide the chat panel

Click the **Hide chat** button located in the **Preview** section. This action collapses the chat view.

Click the **Search** button. This allows you to find content across your workspace.
